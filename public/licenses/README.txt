ALYS Pool Manager uses the unmodified heic-to 1.6.7 CSP build for local HEIC/HEIF conversion. It is LGPL-3.0-or-later and includes libheif. No external conversion service receives photographs.

Underlying libheif source/license: https://github.com/strukturag/libheif
Install the pinned dependency via npm ci; replace/rebuild the module via the application source without altering visit records or IndexedDB.
